# Історія розробки (Changelog)

## Ітерація 1: Ініціалізація та налаштування архітектури
- Створено фронтенд-частину на базі **Vite + React + TypeScript**.
- Налаштовано **React Flow** для побудови node-based інтерфейсу.
- Створено кастомні вузли:
  - `InputNode`: Базовий вузол для тексту та інструкцій.
  - `ComponentNode`: Вузол для налаштувань промпту (Камера, Стиль, тощо).
  - `OutputNode`: Фінальний вузол, що формує текстовий промпт та дозволяє його скопіювати.
- Реалізовано темний сучасний дизайн (glassmorphism) у `index.css`.
- Додано бокову панель (`Sidebar`) з бібліотекою типових налаштувань (камера, світло, стиль) для перетягування (Drag & Drop) на полотно.
- Створено бекенд-частину на **Node.js** з використанням `@modelcontextprotocol/sdk`.
- Налаштовано MCP Сервер для роботи як плагін у **LM Studio** через `stdio`.
